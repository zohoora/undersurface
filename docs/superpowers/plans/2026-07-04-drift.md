# Drift Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Drift — a bilateral dual-attention regulation practice (EMDR-resourcing/SE-pendulation lineage, reprocessing loop designed OUT) — as a flag-gated guided exercise launched from the Relax surface, in text + voice.

**Spec:** `docs/superpowers/specs/2026-07-04-drift-design.md` — READ IT FIRST. The spec is authoritative on intent; this plan is authoritative on mechanics.

**Architecture:** A pure reducer state machine (`driftEngine.ts`) owns all flow, caps, and routing in both modalities. A React hook (`useDriftSession`) drives it, persists to a new `driftSessions` collection, streams between-set exchanges through the existing `/api/chat` path, and wires the existing two-layer crisis stack. Voice is a delivery adapter (`useDriftVoice`) over the existing `useVoiceSession` Realtime hook — the engine keeps authority; the model only speaks. BLS is a local Web Audio + DOM component.

**Tech stack:** React 19 functional components, TypeScript strict, Vitest + jsdom + @testing-library, Firestore via `db.ts` proxies, Web Audio API, OpenAI Realtime via existing WebRTC hook. No new dependencies.

## Global Constraints

Copied from the spec + repo rules. Every task implicitly includes these:

- **No semicolons, single quotes** (repo lint style). TypeScript strict — no `any`; `import type {}` for type-only imports.
- **Type gate is `npx tsc -b --force`** — never `tsc --noEmit -p tsconfig.json` (checks zero files). A green `npm run build` is NOT proof of type-safety.
- **Lint gate on exit code** — run `npm run lint` bare, never piped. No `Date.now()` in render-scoped functions (React Compiler purity rule) — clocks live in effects/refs or are injected into pure functions as parameters.
- **The string "EMDR" must never appear in product UI strings or prompts.** It may appear only in code comments, docs, and the spec. (Enforced by a test in Task 5.)
- **No numeric distress scale anywhere** — no 0–10 anything. Directional pills (softer/same/stronger) are the only permitted check-in.
- **The companion never re-invokes the starting point once the flow leaves `baseline`** — no state, prompt, or copy may instruct a return to it. Stuck/capped → closure. (The defining inversion; tested in Tasks 3 and 6.)
- **Scripted safety copy** (arrive/anchor/settle/closure/abort) is fixed i18n strings, never LLM output.
- **BLS bounds:** pass duration clamped 1500–2500ms; set length 25s (must stay ≤30s); set cap 8; session cap 12 min.
- **`driftEnabled` is default OFF** (experimental flag, `=== true` check). Entry hidden while grounding is active.
- **i18n:** every user-visible string added to ALL 17 locale files (key-parity test enforces this — adding en-only keys breaks the suite).
- **Commit after every green task.** Conventional-commit style (`feat(drift): …`), each commit message ends with the two footer lines already used in this repo's recent history (Co-Authored-By + Claude-Session; substitute the executing session's own values).

export type DriftEvent =

  | { type: 'BASELINE_DONE' } | { type: 'SET_COMPLETE' }

  | { type: 'CLOSURE_DONE' } | { type: 'TICK'; elapsedMs: number }
export const DRIFT_LIMITS = { setTarget: 6, hardSetCap: 8, maxSessionMs: 720_000, passMsMin: 1500, passMsMax: 2500, setMs: 25_000, stillnessMs: 4_000 } as const

export function driftReduce(state: DriftState, event: DriftEvent): DriftState
export function outcomeForReason(reason: ClosureReason): DriftOutcome  // stuck|cap → 'settled'; user|settle → 'eased_early'; crisis → 'aborted_to_grounding'
export function selectInterweave(text: string, opts: { lastInterweave: InterweaveKind | null; grounding: boolean; userPartNames: string[] }): InterweaveKind | null
export function blsPan(elapsedMs: number, passMs: number): number  // smooth [-1, 1]
export function clampPassMs(ms: number): number

**Semantics (implement exactly):**
- `BEGIN`: arrive→anchor. `ANCHOR_CONFIRMED`: anchor→choose. `STARTING_POINT`: choose→baseline. `BASELINE_DONE`: baseline→set.
- `SET_COMPLETE`: set→notice, `setCount + 1`.
- `NOTICE` (in notice): `risk === 2` → closure(crisis). Else if `direction === 'stronger'` or `risk === 1`: if `inSettleRecheck` → closure('settle' — the settle detour didn't land; spec: "re-check → continue or closure"; outcome maps to 'eased_early') else → settle, `inSettleRecheck = true`. Else if `direction === 'same'`: `sameStreak + 1`; streak ≥ 2 → closure(stuck), else → set. Else (softer/skipped): reset `sameStreak`, clear `inSettleRecheck` → set. BUT first, on every path that would go to `set`: if `setCount >= DRIFT_LIMITS.setTarget` → closure(cap). (`hardSetCap` is a belt-and-suspenders bound: reducer must never allow setCount to exceed it.)
- `SETTLE_DONE`: settle→notice (the re-check; `inSettleRecheck` stays true until a non-stronger notice).
- `REQUEST_CLOSE` (any phase after anchor, before closure): → closure(user).
- `CRISIS` (ANY phase incl. arrive/closure): → closure(crisis); if already `closed`, no-op. `closureReason` 'crisis' is sticky — later events must not overwrite it.
- `TICK`: updates `elapsedMs`; in set/notice/settle with `elapsedMs >= maxSessionMs` → closure(cap).
- `CLOSURE_DONE`: closure→closed. No other transition reaches `closed`.
- No event may EVER transition to an earlier phase (arrive/anchor/choose/baseline are one-way; there is no event that re-enters baseline or choose — this is the no-return-to-target invariant expressed structurally).
- `selectInterweave`: `grounding` → null. Lowercase text. parts: contains 'part of me'/'a part '/'voice in me' or any name from `userPartNames` (case-insensitive whole-word) → 'parts'. rain: emotion-heavy — any of 'ashamed','shame','sad','grief','hurt','lonely','scared','afraid','tender','miss ','missing','cry','tears','heavy' → 'rain'. defusion: thought-framing — 'i keep thinking','the thought','i tell myself','story','should have','shouldn’t','always ruin','never get','i’m such' → 'defusion'. focusing: body-vague — 'tight','knot','chest','throat','stomach','pressure','warm','cold','numb','buzz','heavy in' (body word without a matched emotion word) → 'focusing'. Priority when several match: parts > rain > defusion > focusing (parts is rarest + most personal; rain covers tenderness first per spec intent). If chosen === `opts.lastInterweave` → null (cooldown 1 exchange). No match → null.
- `blsPan(elapsed, passMs)`: `Math.sin((elapsed / clampPassMs(passMs)) * Math.PI)` folded into a triangle-free smooth sweep: use `Math.sin(Math.PI * (elapsed % (2 * p)) / p - Math.PI / 2)` where `p = clampPassMs(passMs)` — one full left↔right cycle per `2 * passMs`, continuous, no snap. `clampPassMs` clamps to [1500, 2500].

```tsx
import { useEffect, useRef } from 'react'
import { blsPan, clampPassMs } from '../../../engine/driftEngine'
import type { DriftBlsChannel } from '../../../types'

interface Props { channel: DriftBlsChannel; running: boolean; passMs: number; volume: number }

function prefersReducedMotion(): boolean {
  try { return window.matchMedia('(prefers-reduced-motion: reduce)').matches } catch { return false }
}

export function BilateralStimulus({ channel, running, passMs, volume }: Props) {
  const dotRef = useRef<HTMLDivElement>(null)
  const rafRef = useRef(0)
  const audioRef = useRef<{ ctx: AudioContext; panner: StereoPannerNode; gain: GainNode } | null>(null)
  const effectiveChannel: DriftBlsChannel = channel === 'visual' && prefersReducedMotion() ? 'audio' : channel

  // Audio: soft tick alternating sides. One oscillator burst per side-arrival.
  useEffect(() => {
    if (!running || effectiveChannel !== 'audio') return
    const ctx = new AudioContext()
    const panner = new StereoPannerNode(ctx)
    const gain = new GainNode(ctx, { gain: 0 })
    gain.connect(panner).connect(ctx.destination)
    audioRef.current = { ctx, panner, gain }
    const p = clampPassMs(passMs)
    let side = -1
    const tick = () => {
      const { ctx: c, panner: pan, gain: g } = audioRef.current ?? {}
      if (!c || !pan || !g) return
      pan.pan.setValueAtTime(side, c.currentTime)
      const osc = new OscillatorNode(c, { type: 'sine', frequency: 220 })
      osc.connect(g)
      g.gain.cancelScheduledValues(c.currentTime)
      g.gain.setValueAtTime(0, c.currentTime)
      g.gain.linearRampToValueAtTime(0.18 * volume, c.currentTime + 0.03)
      g.gain.exponentialRampToValueAtTime(0.0001, c.currentTime + 0.28)
      osc.start()
      osc.stop(c.currentTime + 0.3)
      side = -side
    }
    tick()
    const id = setInterval(tick, p)
    return () => { clearInterval(id); void ctx.close(); audioRef.current = null }
  }, [running, effectiveChannel, passMs, volume])

  // Visual: dot swept by blsPan on rAF.
  useEffect(() => {
    if (!running || effectiveChannel !== 'visual') return
    const start = performance.now()
    const animate = (now: number) => {
      const pan = blsPan(now - start, passMs)
      if (dotRef.current) dotRef.current.style.transform = `translateX(${pan * 42}vw)`
      rafRef.current = requestAnimationFrame(animate)
    }
    rafRef.current = requestAnimationFrame(animate)
    return () => cancelAnimationFrame(rafRef.current)
  }, [running, effectiveChannel, passMs])

  if (!running || effectiveChannel !== 'visual') return null
  return (
    <div aria-hidden style={{ position: 'absolute', inset: 0, display: 'flex', alignItems: 'center', justifyContent: 'center', pointerEvents: 'none' }}>
      <div ref={dotRef} data-testid="bls-dot" style={{ width: 14, height: 14, borderRadius: '50%', background: 'var(--text-primary)', opacity: 0.55 }} />
    </div>
  )
}
```
